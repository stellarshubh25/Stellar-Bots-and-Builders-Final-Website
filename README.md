# Stellar Bots and Builders redesign

Open `index.html` in a modern browser. No build step or installation is needed.

## Before publishing

1. Replace the visible tagline placeholder, WhatsApp link/number, email address, and location in `index.html` with the real details.
2. Replace the demo placeholder with a compressed real chatbot screenshot or short mobile screen recording.
3. Have the `privacy.html` and `terms.html` content reviewed for the applicable jurisdiction and your actual data practices.

## Included

- Responsive homepage with a static mobile chatbot example
- Collapsible keyboard-accessible mobile navigation
- Privacy and terms pages
- No animations, gradients, stock images, AI-generated imagery, icon sets, or JavaScript libraries
